The `cp*-names.zip` archives contain names encoded in the code page given in
the filename. They have neither the UTF-8 flag nor Unicode path extra fields.

- `cp437-names.zip`: `¢.txt` (the same byte is `ø` in CP850).
- `cp720-names.zip`: `إجابات.txt`.
- `cp949-names.zip`: `가.txt`.
- `cp852-names.zip`: `Úlohy/`, `Úlohy/Varianta 1.txt`, `Odpovědi.txt`.
- `cp855-names.zip` and `cp866-names.zip`: `Задания/`,
  `Задания/Вариант 1.txt`, `Ответы.txt`.

The CP437, CP720, CP852, CP855 and CP949 archives use stored entries; each file
contains `legacy contents` followed by a newline. Directory entries are empty.
